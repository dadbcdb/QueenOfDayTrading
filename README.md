# 주식일지 — 갤럭시용 국내주식 기록 앱

키움 REST API로 국내주식 거래 내역과 일별 실현 손익을 가져오고, 거래별 매매일지를 기기에 저장하는 안드로이드 앱입니다. Android 8.0 이상에서 실행합니다.

앱 상단과 계좌 설정에서 설치된 버전·빌드 번호를 확인할 수 있습니다. 현재 배포본은 **v0.1.3 (빌드 4)**입니다. 업데이트는 기존 앱 위에 설치하면 됩니다. 오류 문의 시 버전과 전체 오류 문구를 함께 확인하세요. 키움 응답에 상세 코드가 없다면 **상세코드 없음**으로 표시합니다.

## 설치 및 연결

1. `release/stock-diary-debug.apk`를 갤럭시폰으로 옮겨 실행합니다. 파일을 연 앱에 설치 권한이 필요할 수 있습니다.
2. 앱의 **계좌 설정**에서 App Key와 Secret Key를 입력하고 저장합니다. 실제 계좌 거래 기록에는 실전용 키를 사용합니다.
3. 폰이 사용하는 네트워크의 공인 IP를 키움 REST API 포털에 등록합니다. 폰을 해당 Wi-Fi에 연결합니다. 모바일망도 허용 IP 등록 조건을 만족해야 합니다.
   **연결 확인 · 인증만 테스트**를 누르면 거래 내역을 조회하지 않고 인증 가능 여부를 먼저 확인합니다. 실패 시 인증·거래·일별 손익·종목별 손익·보유 종목 중 어느 단계에서 실패했는지와 오류 코드를 표시합니다.
4. 시작일·종료일을 선택하고 **선택한 기간 가져오기**를 누릅니다.
5. **거래 내역**에서 거래를 눌러 일지를 작성합니다. 저장된 기록은 인터넷 없이 볼 수 있습니다.

인증키 없이도 **샘플 데이터로 둘러보기**가 가능합니다. 샘플 기록은 실제 계좌와 따로 저장되며 샘플로 표시합니다.

## 데이터와 계산 기준

- `kt00015`: 거래일(`trde_dt`) 기준으로 국내주식 매매 내역을 조회합니다. 거래일과 체결일(`cntr_dt`)은 다를 수 있으므로 모두 표시합니다. KRX/NXT 거래를 함께 요청합니다.
- `ka10074`: 키움의 일별 실현 손익(`tdy_sel_pl`)을 그대로 합산합니다. 수수료·세금은 별도로 표시하며 실현 손익에서 다시 차감하지 않습니다. 월별 손익은 저장된 일자만 합산하므로 월 전체를 조회하지 않았다면 부분 합계입니다.
- `ka10073`: 종목별 실현 손익을 조회하여 저장된 일자 범위에서 종목별로 합산합니다.
- `kt00004`: KRX 기준 보유 종목 평가와 평균 단가를 표시합니다. 동기화 시점의 조회 결과이며 실시간 시세가 아닙니다.
- 조회한 거래일 범위와 손익일 범위는 각각 교체합니다. 다른 기간은 유지합니다. 거래일+거래번호로 거래를 식별해 중복을 막고 일지를 유지합니다.
- 네 조회가 모두 완료되고 검증을 통과하면 SQLite 트랜잭션 한 번으로 저장합니다. 통신 오류, 페이지 누락, 중복 식별번호, 비정상 날짜가 있으면 기존 기록을 유지합니다.
- 실전·모의 및 App Key별로 저장 공간을 분리합니다. 키 재발급 시 자동으로 예전 기록과 합치지 않습니다. 먼저 이전 기록을 백업하세요.
- 서버가 API 조회 가능 기간을 제한할 수 있습니다. 앱에서는 최대 1년 단위로 요청하며, 키움이 기간을 거절하면 기간을 줄여야 합니다. 전체 과거 이력을 반드시 제공한다고 가정하지 않습니다.

## 인증 및 보관

App Key와 Secret Key는 Android Keystore의 AES-GCM 키로 암호화하여 앱 내부에 저장합니다. 접근토큰은 조회 동안 메모리에서만 사용합니다. 계좌 데이터는 앱 내부 SQLite에 저장하며 Android 시스템 백업을 비활성화합니다. 앱 화면 캡처도 제한합니다. 앱 삭제 시 로컬 기록과 키가 삭제됩니다.

매매일지·거래·손익·보유 종목은 JSON 백업으로 내보낼 수 있습니다. 인증키와 토큰은 백업에 포함하지 않습니다. 백업에는 거래정보가 포함되며 사용자가 선택한 파일 위치에 저장됩니다. 현재 버전에는 백업 복원 기능이 없습니다.

API 클라이언트는 토큰 발급과 위 네 조회만 제공합니다. 주문 API는 구현하지 않았습니다. 비밀키를 소스 코드, Git 또는 채팅에 넣지 마세요.

## 빌드와 검증

JDK 17 이상(개발 시 JDK 21), Android SDK 35 및 Gradle wrapper를 사용합니다. Android Studio에서 프로젝트를 열거나 아래 명령을 실행합니다.

```powershell
# local.properties에 본인의 Android SDK 경로 설정
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

로컬 개발 도구는 `.tools/`에 설치되어 있으며 Git에서 제외됩니다. `scripts/build.ps1`은 현재 프로젝트의 도구를 자동 감지해 빌드하고 APK를 `release/`에 복사합니다.

JVM 테스트는 실제 키 없이 HTTP 테스트 서버로 국내주식 요청값, 인증, 연속조회, 페이지 반복 오류, HTTP 오류의 비밀정보 비노출, 취소, 숫자 파싱, 거래 식별과 계좌 분리를 검증합니다. 실제 키움 계좌 연결과 갤럭시 실기기 화면 검증은 별도로 필요합니다.
